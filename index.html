盈利后的拟议路径

经核算的可分配运营净收益 → 从市场买入 KEY → 按方案 1:1 转为 wKEY → 从单剧池买入该剧 IP 代币 → 销毁买回的 IP 代币。

回购会产生买入需求，销毁会减少买回代币的供应。价格仍由后续买卖和池深决定。

持有人的拟议退出路径

单剧 IP 代币 → 在池中卖出换 wKEY → 按方案 1:1 兑回 KEY → 通过支持的交易渠道换为目标稳定币。

1:1 指 KEY 与 wKEY 的方案兑换比例。团队讨论中称目标稳定币为 USDat，正式币种和交易对仍待确认。兑付、成交价和可退出数量取决于项目规则和流动性。出售可能获利或亏损。

本页按团队当前方案展示 IP 代币销毁。此前西安发布会报道另有回购并销毁 KEY 的规划，两者涉及不同资产，执行以正式项目规则为准。

UniKey · 从基础用量到 Agent 服务

  • 购买额度
    白皮书设计允许用 KEY 购买 AI Credits，用于模型、API 与平台内 AI 服务。
  • 使用 Agent Skills
    白皮书规划 KEY 用于购买、订阅或调用 Agent Skills，具体可用范围以产品为准。
  • 持续使用额度
    按白皮书的 KEY Credits Vault 规则，存入 KEY 可获得每日 AI Credits 模型额度，赎回后停止后续释放。

多剧到多生态

项目越多，KEY 会沉淀得越多吗？

在相同参数下，每新增一部剧可带来 600 KEY 的初始配对预算。存量池里的 KEY 等值，要看其后资金怎么进出。

初始配对预算模拟

6,000 KEY项目数 × 600 KEY。仅表示按同一规则初始化配对的预算。

用资金流判断净沉淀

增加 · 新池注入、追加流动性、回购 IP 时进入池子的 wKEY。

减少 · 用户卖出 IP 换走 wKEY、流动性撤出及其他净流出。

看期末净储备、池深与撤出规则。wKEY 的储备和其 KEY 底层支持资产按等值统计一次。

验证单剧先用预告验证需求，再检验制作成本、发行与结算
复制到多剧统一项目披露、池深和净储备口径
扩展到多生态适配的项目可发行独立代币并采用 KEY／wKEY 作为配对资产
KEY 的用途怎样扩大

如果更多项目持续使用 KEY，KEY 就能出现在发行预算、LP 配对、交易结算和可核对的运营回购等多种场景。市场由此可以按项目看用户、收入、交易和流动性。各池以 KEY 配对也会共享 KEY 波动，流动性仍分布在各自池中。
